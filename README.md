# מתכוני סבתא שרה — אתר משפחתי

אתר סטטי (HTML/CSS/JS בלבד). אין שרת, אין בסיס נתונים, אין תלות באינטרנט חיצוני.
לפתיחה: לחיצה כפולה על `index.html`.

---

## מה צריך להשלים

| # | מה | איפה |
|---|-----|------|
| 1 | שם הרחוב/השכונה על השלט | ראו "השלט" למטה |
| 2 | תמונות של סבתא שרה לגלריה | `SITE.photos` בקובץ `assets/js/data.js` |
| 3 | אישור/עריכה של טקסט הפתיחה | `SITE.intro` בקובץ `assets/js/data.js` |
| 4 | זמן הכנה וכמות מנות (אופציונלי) | ראו "זמן הכנה וכמות" למטה |
| 5 | השלמת אופן ההכנה של קרפלך | ראו "הערות על התוכן" למטה |

**המתכונים כבר בפנים** — 24 מתכונים: 3 סלטים, 4 מרקים, 7 עיקריות, 4 תוספות, 6 קינוחים.

## הוספת מתכון

כל התוכן נמצא בקובץ אחד: **`assets/js/data.js`**. אין צורך לגעת בשום קובץ אחר,
ואין צורך ליצור דף חדש לכל מתכון — הדף נבנה לבד.

להעתיק בלוק קיים מתוך `RECIPES` ולערוך:

```js
{
  id: "shnitzel",              // מזהה באנגלית, ייחודי, בלי רווחים
  category: "mains",           // salads / soups / mains / sides / desserts
  image: "",                   // או "assets/img/recipes/shnitzel.jpg"
  time: "",                    // אפשר "" והשורה לא תוצג
  servings: "",                // אפשר ""
  he: {
    title: "שניצל של סבתא",
    ingredients: ["4 חזה עוף פרוס דק", "2 ביצים"],
    steps: ["לרדד את החזה בין שתי שקיות.", "לטבול בביצה ובפירורים ולטגן."],
    note: "אפשר להכין מראש ולהקפיא."      // אופציונלי
  },
  en: {
    title: "Savta's Schnitzel",
    ingredients: ["4 thin-sliced chicken breasts", "2 eggs"],
    steps: ["Flatten the breasts between two bags.", "Dip in egg and crumbs, then fry."],
    note: "Can be made ahead and frozen."
  }
}
```

אם ממלאים רק את `he` ומשמיטים את `en`, המתכון יוצג בעברית גם בגרסה האנגלית.

הכרטיס בקטגוריה, דף המתכון, פירורי הלחם והחיפוש — כולם מתעדכנים לבד.

### האייקונים שקופצים מהקטגוריה

לכל קטגוריה ב-`CATEGORIES` יש רשימת `icons`. אלה שמות הקבצים שבתוך
`assets/img/icons/` (בלי `.png`), והם אלה שקופצים מהכרטיס בריחוף או בנגיעה.
להחלפה — פשוט לשנות שמות ברשימה. 3 עד 5 אייקונים זה הטווח שנראה הכי טוב.

האייקונים הזמינים כרגע: candy, carrot, celery, chicken, corn, cucumber,
cupcake, drumstick, eggplant, lettuce, measuringcup, onion, pancake, pretzel,
rollingpin, tomato.

האייקונים האלה משמשים גם כממלאי־מקום בכרטיסי המתכונים שאין להם תמונה — כל מתכון
מקבל אייקון אחר מהרשימה לפי מיקומו בקטגוריה, כדי שלא תחזור אותה תמונה בכל השורות.

### כותרות ביניים ברשימת המצרכים

מתכון עם בצק ומילוי, או עם קציצות ורוטב, מחולק בעזרת שורה שנגמרת בנקודתיים.
שורה כזאת מוצגת ככותרת ולא כמצרך לסימון:

```js
ingredients: [
  "לבצק:",
  "2 כוסות קמח",
  "מלח",
  "למילוי:",
  "1/2 ק\"ג תפוחי אדמה מבושלים"
]
```

### הערות על התוכן

- **קרפלך** — אופן ההכנה שנמסר נגמר בהכנת הבצק והמילוי, בלי שלב המילוי, הסגירה
  והבישול. לא הוספנו שלבים מעצמנו. כשיהיה ההמשך, להוסיף אותו למערך `steps`.
- **פרפרים (Minciunele)** — השם נכתב עם העברית קודם, כדי שיוצג נכון בעמוד מימין
  לשמאל. אפשר לשנות בשדה `title`.

## הוספת תמונות של סבתא (הגלריה בדף הבית)

1. לשים את קבצי התמונות בתוך `assets/img/gallery/`
2. בקובץ `data.js`, למלא את `SITE.photos`:

```js
photos: [
  { src: "assets/img/gallery/savta-01.jpg", caption: "סבתא במטבח, 1998" },
  { src: "assets/img/gallery/savta-02.jpg", caption: "" }
]
```

כל עוד הרשימה ריקה, הגלריה מציגה מסגרות ריקות עם הכיתוב "כאן תיכנס תמונה של סבתא".
מומלץ 5–8 תמונות ברוחב של עד 1200 פיקסלים כל אחת, כדי שהאתר ייטען מהר בטלפון.

תמונות של מנות: לשים ב-`assets/img/recipes/` ולציין את הנתיב בשדה `image` של המתכון.

## השלט בדף הבית

השלט הוא קובץ תמונה: `assets/img/street-sign.png` — הרקע הוסר והאיור הומר לקו שחור בלבד,
כך שהוא יושב על כל רקע.
הטקסט **"רח' קפלן / דגל ראובן" צרוב בתוך התמונה** ולא ניתן לעריכה בקוד.

אם זה השם הנכון — אין מה לעשות. אם צריך שם אחר, יש להחליף את הקובץ בתמונה חדשה
באותו סגנון (שמירה על אותו שם קובץ, והרקע שקוף). כדאי לעדכן גם את `SITE.signAlt`
ב-`data.js`, שזה התיאור לקוראי מסך.

**שימו לב אם מחליפים את התמונה:** עמוד השלט ממשיך למטה לאורך הדף, עובר מאחורי
התמונות ונמוג. ההמשך הזה הוא קובץ נפרד — `assets/img/post-tile.png` — רצועה של
העמוד שחוזרת על עצמה. הוא חתוך מהתמונה המקורית ומיושר אליה לפי אחוזים שרשומים
ב-`style.css` (המחלקה `.signpost__post`, כרגע `left: 32.79%` ו-`width: 13.41%`,
שמתאימים לעמוד שנמצא בפיקסלים 220–310 מתוך רוחב של 671).
בתמונה חדשה צריך לחתוך רצועה חדשה ולעדכן את שני האחוזים, אחרת ההמשך לא יתיישר.

## זמן הכנה וכמות מנות

התשתית קיימת. כרגע רק לקוגל ירושלמי יש כמות מנות (5–6), כי זה הנתון היחיד שנמסר —
בכל שאר המתכונים השדות `time` ו-`servings` ריקים. כשהשדה ריק השורה פשוט לא מופיעה
בדף, אז אין שום דבר שבור.

כדי להציג את השורה במתכון מסוים, למלא:

```js
time: "40 דקות",
servings: "4 מנות",
```

אפשר גם למלא רק חלק מהמתכונים — כל מתכון עומד בפני עצמו.

## שתי שפות

האתר קיים בעברית ובאנגלית, **מאותם ארבעה דפים** — לא שוכפל. הכפתור למעלה
מוסיף `?lang=en` לכתובת, הבחירה נשמרת בדפדפן, וכל קישור פנימי נושא אותה איתו.
בעברית הדף `dir="rtl"`, באנגלית `dir="ltr"` והפריסה מתהפכת לבד.

**איפה עורכים מה, ב-`data.js`:**

| מה | איפה |
|-----|-------|
| טקסטים של הממשק (תפריט, כפתורים, כותרות) | `STRINGS.he` / `STRINGS.en` |
| שמות הקטגוריות | `CATEGORIES` — שדות `he` ו-`en` |
| מתכונים | לכל מתכון בלוק `he` ובלוק `en` |
| דף "עלינו" | `ABOUT.he` / `ABOUT.en` |
| פסקאות הפתיחה | `SITE.intro` |

אם משאירים שדה אנגלי ריק, מוצג הטקסט העברי במקומו — אז אפשר להוסיף מתכון
בעברית בלבד והאתר לא יישבר.

## גופנים

- **עברית: ירדן.** הגופן היחיד בצד העברי.
- **אנגלית: Poppins.** לירדן אין בכלל אותיות לטיניות (0 מתוך 52), אז בלי זה
  הצד האנגלי היה רץ על גופן ברירת מחדל של הדפדפן. Poppins נבחר כי הגיאומטריה
  שלו זהה לירדן: עיגולים מלאים, עובי קו אחיד, סיומות חתוכות ישר.
- גובה ה-x של שניהם שונה ב-0.4% בלבד, אז טקסט הגוף באותו גודל בדיוק. הכותרות
  באנגלית גדולות ב-8% כי האותיות הגדולות של Poppins נמוכות יותר.
- שני הגופנים מותקנים מקומית. דף עברי לא מוריד את Poppins ולהפך.
- רישיונות: `assets/fonts/free-font-license.pdf` (ירדן), `poppins-OFL.txt`.

## מובייל

רשימת המתכונים בטלפון מוצגת כשורות ולא ככרטיסים גדולים — אייקון בצד, שם המתכון
לידו. כל עוד אין תמונות מנות זה מקצר את הגלילה מ-8300 פיקסלים ל-2100 והופך את
הרשימה לסריקה מהירה. **ברגע שמוסיפים תמונה למתכון היא נכנסת לריבוע וממלאת
אותו** — אין צורך לשנות שום דבר.

## שיתוף ומצב בישול

בכל דף מתכון יש שני כפתורים:

**שיתוף** — בטלפון נפתח גיליון השיתוף של המערכת (וואטסאפ, הודעות, מייל).
במחשב הקישור פשוט מועתק ומופיעה הודעה קטנה. הקישור כולל את השפה, אז מי שמשתף
מהגרסה האנגלית — הנמען יפתח באנגלית.

**בישול שלב אחר שלב** — מסך מלא עם שלב אחד גדול בכל פעם, פס התקדמות, ורשימת
המצרכים נפתחת מלמטה בלי לצאת מהשלב. מעבר בכפתורים, בחיצים במקלדת, או בהחלקה
באצבע. בסוף מסך "סיימנו!" עם אפשרות לחזור להתחלה. `Esc` סוגר.
בזמן שהמצב פתוח **המסך לא נכבה** (Wake Lock), כדי שלא ייכבה באמצע הבישול.

⚠️ **שתי היכולות האלה דורשות HTTPS.** כשפותחים את הקובץ בלחיצה כפולה
(`file://`) גיליון השיתוף ונעילת המסך לא יעבדו — השיתוף יתחלף בהעתקה רגילה.
אחרי העלאה לאחסון (Netlify וכו') הכל עובד. זו מגבלה של הדפדפן, לא באג.

## אם שינוי לא מופיע בדפדפן

הדפדפן שומר בזיכרון את קבצי העיצוב והקוד, ולפעמים ממשיך להציג גרסה ישנה
גם אחרי שהקובץ באמת השתנה. כדי למנוע את זה, הקישורים ל-`style.css`,
`data.js` ו-`site.js` בארבעת דפי ה-HTML נגמרים ב-`?v=20260811a`.

**אחרי כל שינוי ב-CSS או ב-JS צריך להעלות את המספר הזה** (למשל ל-`20260811b`)
בכל ארבעת הדפים — וכל מי שיפתח את האתר יקבל את הגרסה החדשה מיד.

לרענון מיידי בלי לשנות כלום: `Ctrl + Shift + R` בדפדפן.

## נגישות ותאימות

- האתר בעברית מלאה, `dir="rtl"`.
- מותאם לטלפון (וזאת הדרך העיקרית שבה המשפחה תראה אותו).
- ניווט מלא במקלדת, סימון פוקוס ברור, קישור "דילוג לתוכן".
- מכבד `prefers-reduced-motion` — למי שהגדיר במערכת ההפעלה הפחתת אנימציות,
  הגלריה נעצרת והתנועות מתבטלות.
- הדפסה: דף מתכון מודפס נקי, בלי תפריטים וקישוטים.
